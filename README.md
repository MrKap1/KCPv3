# 👕 Kaps Clothing Pack (KCP) - V3

Welcome to **V3** of the Kaps Clothing Pack (KCP)! This pack is the third installment in the series, further continuing to bring a variety of new clothing options to your game or project.

---

## 📦 About This Release

This repository contains the third version (**V3**) of the Kaps Clothing Pack. It includes a substantial set of clothing assets that build upon the previous versions.

## ⬇️ How to Get the Full Collection

The Kaps Clothing Pack is a continuing project spread across multiple versions. **V3 is a continuation pack.** To ensure you have access to **all** the clothing assets KCP has to offer, you will need to download **all four** currently available versions:

* **V1** (Initial Pack)
* **V2** (Continuation Pack)
* **V3** (This Repository - Continuation Pack)
* **V4** (Continuation Pack)

Please check the main KCP developer page or the relevant links to locate and download the V1, V2, and V4 packages.

---

## 🛠️ Installation & Usage

Installation is simple!

1. **Drag and Drop** the files into your game's directory.
2. **Ensure** you have also downloaded and installed **V1, V2, and V4** for the complete Kaps Clothing Pack collection.
